# Fichas Moove

Protótipo do app de fichas de treino da academia Moove Wellness.

- Aluno: abre o treino no celular, marca cada série e usa o cronômetro de descanso.
- Professor: monta e edita a ficha de cada aluno.

Demonstração: os dados são de exemplo e ficam salvos apenas no aparelho de quem acessa.

Site: https://fichasmoove.github.io

Publicado via GitHub Pages.
